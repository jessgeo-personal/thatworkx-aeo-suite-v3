❓ What is AEO?

Answer Engine Optimization vs SEO

Traditional SEO focuses on keyword stuffing for human rank. AEO structures clean data layouts that RAG systems, LLMs, and agentic crawlers can index and cite.

Traditional SEO

Modern AEO / GEO
  • ✔ Flat markdown directory routes

A strict 4-level file structure ensures AI crawlers can retrieve metadata without executing JavaScript. Missing any level reduces your AI citation potential significantly.

  • Level 1 — robots.txt: Global gatekeeper. Explicitly allow GPTBot, ClaudeBot, and PerplexityBot. Absence = blocked by default on many LLM indexers.
  • Level 2 — llms.txt: Machine-readable directory standard. Maps site architecture, key content paths, and references external social proof anchors.
  • Level 3 — ai-context.md: Corporate verification manifest. Contains brand mission, NAICS code, E-E-A-T anchors, and system-prompt injection blocks.
  • Level 4 — Flat Markdown pages: Target content served as zero-noise text payloads. No heavy scripts, no SPA hydration barriers.

LLMs prioritise sources with verifiable author credentials, freshness signals, and structured schema. The E-E-A-T Citation Authority Engine audits all three layers and prescribes fixes.

  • Author Credentials: Verified via schema.org/Person JSON-LD blocks with knowsAbout, sameAs (LinkedIn / ORCID), and affiliation fields.
  • Freshness Anchors: dateModified and datePublished in ISO 8601 format on every page. Stale content loses citation weight over 90 days.
  • Schema Validation: Full JSON-LD Article, Organization, and FAQPage schemas validated against Google Rich Results and AI engine expectations.
  • External Authority Links: Outbound links to PubMed, GOV, IEEE, or verified institutional domains boost RAG trustworthiness scores.

# AEO crawlability gate — run after deploy

  -H "Authorization: Bearer $AEO_SECRET_TOKEN" \
