🧩 Chrome Extension Integration Hub

The AISocialize browser extension enables content creators to append machine-readable citation snippets directly while writing on LinkedIn, Reddit, or Medium.

Setup Instructions:
  1. Download the AISocialize extension bundle (`.zip`).
  2. Navigate to chrome://extensions in your browser.
  3. Enable Developer Mode toggle in top right corner.
  4. Click Load Unpacked and select the downloaded folder.
